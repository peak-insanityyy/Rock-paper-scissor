# Rock Paper Scissors

A simple Rock Paper Scissors game you play against the computer, built with plain HTML, CSS and JavaScript. Your score is saved in the browser, so it's still there after a refresh.

## Features

- Play Rock, Paper or Scissor against a random computer move
- Live win / loss / tie scoreboard
- Score saved with `localStorage`
- Reset button to clear the score

## Run it locally

No install needed.

1. Clone the repo:
   ```bash
   git clone https://github.com/<your-username>/rock-paper-scissors.git
   ```
2. Open `index.html` in your browser.
